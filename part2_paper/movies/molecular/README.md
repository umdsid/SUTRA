# SUTRA molecular supplementary movies (6–15)

The ten molecular hierarchy videos are distributed as GitHub Release assets, not duplicated in the Git source tree.

**Release:** https://github.com/umdsid/SUTRA/releases/tag/supplementary-videos-v1

- `numbering_map.csv` and `numbering_map.json`: authoritative numbering supplied with the release.
- `MOLECULAR_MOVIE_MANIFEST.json`: verified release asset names, sizes, download URLs, and SHA-256 checksums where local originals are present.
- `provenance/`: original supplied provenance files, copied unchanged.

Movies 1–5 remain in the existing sibling directories, with their frozen versions documented in `../MOVIE_MANIFEST.json`. The hierarchy videos illustrate changes across organizational scale, not biological time. Molecular pair renderings do not independently establish single-cell coexpression or null-adjusted association.
